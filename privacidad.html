Política de privacidad

Última actualización: 5 de octubre de 2026

Esta política describe cómo la herramienta interna Media Command Center y el canal Nubolín tratan la información. Media Command Center es un programa privado que usa el responsable del canal para subir, programar y analizar sus propios videos en YouTube. No es una app pública: no la usan terceros ni recopila datos de espectadores.

Uso de los servicios de la API de YouTube

Media Command Center usa los Servicios de la API de YouTube. Al usarla, aceptas los Términos del Servicio de YouTube. La información se trata también según la Política de Privacidad de Google.

Qué datos se usan

  • Datos del canal propio (identificador, nombre, lista de videos) para confirmar que la herramienta opera solo sobre el canal Nubolín.
  • Videos propios y sus metadatos (título, descripción, categoría, idioma, fecha de publicación, declaración "creado para niños") para subirlos y programarlos.
  • Estadísticas agregadas de YouTube Analytics de esos videos (vistas, retención promedio, curva de retención, suscriptores ganados) para mejorar los siguientes episodios.

No se recopilan, almacenan ni procesan datos personales de los espectadores, incluidos niños. Los comentarios están desactivados en el canal, como exige YouTube para el contenido creado para niños.

Cómo se guardan y comparten

Los tokens de acceso de OAuth y las estadísticas se guardan solo en la computadora del responsable del canal. No se venden, no se comparten con terceros y no se usan para publicidad. Los datos obtenidos de las APIs de Google se usan conforme a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Conservación y eliminación

Las estadísticas se conservan mientras el canal esté activo, para comparar episodios. Puedes revocar el acceso de la herramienta en cualquier momento desde la página de permisos de seguridad de Google. Al revocarlo, el token deja de funcionar y se elimina de la computadora local.
